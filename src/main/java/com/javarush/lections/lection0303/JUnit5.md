### test pyramid

   - focused to test public API (public methods in class)
2. Service tests - integration, testing interactions between components

### testing principals
- fast - run at any point of development
- isolated / independent - test only one thing at a time
- repeatable / extensible - test should be repeatable and can be extended
- self-validating - test should validate itself without external dependencies
- thorough - test should cover all possible scenarios and edge cases
